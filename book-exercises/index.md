# Preface {.unnumbered}

This is the exercise book of [Privacy-Preserving Machine Learning](../book-full/index.md). It has one page for each chapter of the full edition, numbered like that chapter, and each page has the chapter's exercises with a worked solution for each.

Every exercise names in italics the technique it practises, and most give a check value, so you know when you have the answer. Try each exercise before opening its solution. The solutions use the notation of their chapter, and a reference to an equation, section, figure or table of the chapter links to it in the full edition.

The numbers the solutions quote are computed by scripts in the repository's `code/` directory, one per chapter, named `solutions_<script>.py`, and the tests in `tests/` check each of them.
