1  Probability distributions

1.1 What it is

Most random numbers in a machine-learning system are counts or draws of noise. A count of independent yes-or-no outcomes, each with the same probability, is binomial. When the outcomes are many and each is rare, the count becomes Poisson, whose variance equals its mean.

Noise usually comes from one of two continuous families. The Laplace distribution with scale \(b\) is an exponential density mirrored around zero. The normal distribution is the bell curve, set by its mean and its standard deviation \(\sigma\).

1.2 When you meet it

You meet these families when you size a test set, check which argument of a sampler sets its spread, or put an error bar on a sum.

1.3 How to use it

An error rate \(p\) measured on a test set of \(n\) examples is a binomial count divided by \(n\), so its standard deviation is \[\sqrt{\frac{p(1-p)}{n}}. \tag{1.1}\] With 2,000 examples and a true error rate of 5%, this is about half a percentage point. Divided by \(p\), it becomes a relative standard deviation, which depends on the expected number of errors \(np\) rather than on \(n\). Reaching a relative target \(r\) needs \(n = (1-p)/(p\,r^2)\) examples. For a relative standard deviation of 10%, a 5% error rate needs 1,900 examples, and a rate fifty times smaller needs 99,900.

A sampled batch is the Poisson case. When each of 60,000 examples joins it independently with probability 0.01, its size is close to a Poisson count with mean 600. Its standard deviation is therefore \(\sqrt{600}\), about 24.5.

For noise, you set the spread so that a draw stays within \(t\) of zero except with a failure probability \(\beta\). A Laplace draw with scale \(b\) has standard deviation \(\sqrt2\,b\), not \(b\). Its chance of landing at least \(t\) from zero is \[\Pr[|X| \ge t] = e^{-t/b}. \tag{1.2}\] So the largest Laplace scale and normal standard deviation that meet the target are \[b = \frac{t}{\ln(1/\beta)}, \qquad \sigma = \frac{t}{z_{1-\beta/2}}. \tag{1.3}\] Here \(z_{1-\beta/2}\) is the standard normal quantile. Both formulas split \(\beta\) between the two sides; to bound one side only, replace \(\beta\) by \(2\beta\). For example, Laplace noise of scale 2 stays within \(2\ln 20 = 5.99\) of zero with 95% probability. Table 1.1 shows how differently the two multipliers grow as \(\beta\) shrinks.

On a log scale (Figure 1.1), the Laplace tails fall along straight lines, far above the normal density’s parabola.

Sums of many independent draws look normal by the central limit theorem, but slowly for skewed data. The distribution function of a standardized sum of 30 exponential draws still misses the normal one by up to 0.0243.

A vector of \(d\) independent normal coordinates, each with standard deviation \(\sigma\), has a length close to \(\sigma\sqrt d\), about 10 for a million coordinates at \(\sigma = 0.01\).

The snippet checks these numbers and the integer case described below.

import math

import numpy as np
from scipy import optimize, stats

rng = np.random.default_rng(0)
draws = rng.laplace(loc=0.0, scale=2.0, size=1_000_000)  # scale is b, not the standard deviation
print(f"{draws.std():.3f} {stats.laplace(scale=2.0).std():.4f}")  # 2.832 2.8284
print(f"{stats.laplace(scale=2.0).isf(0.025):.2f}")  # 5.99
print(f"{stats.norm.isf(0.05 / 2):.2f} {stats.norm.isf(1e-3 / 2):.2f} {stats.norm.isf(1e-6 / 2):.2f}")  # 1.96 3.29 4.89
print(f"{math.log(1 / 0.05):.2f} {math.log(1 / 1e-3):.2f} {math.log(1 / 1e-6):.2f}")  # 3.00 6.91 13.82
print(math.ceil((1 - 0.05) / (0.05 * 0.1**2)), math.ceil((1 - 0.001) / (0.001 * 0.1**2)))  # 1900 99900
b = 10 / math.log(1 / 0.01)  # t = 10, beta = 0.01
tail = lambda a: 2 * stats.dlaplace(a).sf(9)  # integer version: P[|K| >= 10]
a = optimize.brentq(lambda a: tail(a) - 0.01, 0.01, 5)
print(f"{b:.4f} {tail(1 / b):.4f} {a:.4f} {tail(a):.4f}")  # 2.1715 0.0123 0.4817 0.0100

1.4 What goes wrong

The commonest bug is a mismatched spread. NumPy’s rng.laplace(0, b) and SciPy’s stats.laplace(scale=b) take the scale \(b\), but rng.normal(0, sigma) and stats.norm(scale=sigma) take the standard deviation, never the variance. So compare the standard deviation of many draws with the intended one. For integer data, draw from an integer distribution rather than rounding. In SciPy’s stats.dlaplace(a), the probability of an integer falls by a factor \(e^{-a}\) per step away from zero, so \(a\) plays the part of \(1/b\). Its tail is heavier, though: \(a = 1/b\) gives 0.0123 where the snippet targets 0.01, so solve for \(a\) numerically. NumPy’s rng.exponential(scale) takes the mean, and rng.geometric(p) counts trials up to and including the first success, so it starts at 1. For tiny tail probabilities, call the tail function sf or its inverse isf, because 1 - cdf rounds to zero.

These formulas assume independent examples, and one user’s rows are not independent, so take \(n\) to be the number of users. The normal approximation to a binomial count needs \(np(1-p)\) of about 10 or more, so it fails for rare events. Finally, the tail bounds of Concentration inequalities need a bounded or light-tailed quantity, so clip an unbounded one, such as a loss, to a range first.
