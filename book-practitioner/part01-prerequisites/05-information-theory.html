5  Information theory

5.1 What it is

Information theory measures how much one quantity tells you about another, with one set of measures for each of two questions. Shannon’s measures ask how many bits an observation saves, on average, when you describe a hidden value. The entropy of a random variable \(X\) is the average number of bits per value that the best compression code needs. With \(p(x)\) for the probability of the value \(x\), and logarithms base 2, it is \[H(X) = -\sum_x p(x)\log_2 p(x). \tag{5.1}\] The mutual information \(I(X; Y)\) is the average drop in the entropy of \(X\) when you see an observation \(Y\). From a joint table it is \(H(X) + H(Y) - H(X, Y)\), where \(H(X, Y)\) is the entropy of the pairs. Unlike a correlation, it is zero only when the two are independent.

The second question asks how much more likely a single best guess becomes. A guesser with one try picks the most likely value, so it wins with the largest probability, the vulnerability \(V(X)\). Its negative logarithm is the min-entropy, \[H_\infty(X) = -\log_2 \max_x p(x), \tag{5.2}\] which is never larger than the entropy.

5.2 When you meet it

Feature selection often ranks features by mutual information, which decision trees call the information gain. Min-entropy matters when a value must be hard to guess, such as a password or an identifier. Use Shannon’s measures for averages and features, and min-entropy for a value that an attacker gets one guess at.

5.3 How to use it

scipy.stats.entropy(p, base=2) returns the entropy of a distribution in bits. For two discrete columns, sklearn.metrics.mutual_info_score(a, b) puts their observed frequencies into the definition of mutual information. Continuous values rarely repeat, so mutual_info_classif in sklearn.feature_selection estimates it from distances to nearest neighbours. The two return nats (natural-log units), so divide by \(\ln 2\) to get bits.

The two measures can disagree a lot. A uniform 4-digit PIN has \(\log_2 10{,}000 = 13.2877\) bits of entropy. If 10% of people choose 1234 and the others choose evenly, the entropy moves only to 12.4278 bits. But the min-entropy falls to 3.3219 bits, because the guess “1234” is correct one time in ten.

To measure how much an output helps one guess, start from two tables. The prior \(\pi(x)\) says how likely each secret is, and the channel \(K[x, y]\) says how likely each output \(y\) is when the secret is \(x\). Multiply each row of the channel by its prior to get the joint table. After \(y\), the best guess is the row with the largest entry in column \(y\). So the chance of a correct guess is the sum of the column maxima: \[V(X \mid Y) = \sum_y\max_x \pi(x)K[x, y]. \tag{5.3}\] The logarithm of \(V(X \mid Y)/V(X)\) is the min-entropy leakage, and 1 bit of it doubles the chance of a correct guess. In the full edition’s example, the output raises that chance from 0.4 to 0.66, a leakage of \(\log_2(0.66/0.4) = 0.7225\) bits.

Without a known prior, use the worst case across priors, the min-capacity, which is the logarithm of the sum of the channel’s own column maxima, 1.2630 bits in the example.

Mutual information can also show that a task is hard, through the uncertainty \(H(X \mid Y) = H(X) - I(X; Y)\) that the output leaves. Take a secret with \(m\) possible values, and a guess from the output with error probability \(P_e\). With \(h(P_e)\) for the entropy of a coin with that bias, Fano’s inequality says \[H(X \mid Y) \le h(P_e) + P_e\log_2(m - 1). \tag{5.4}\] For example, a label uniform across 8 classes has 3 bits of entropy. If the features carry at most 1 bit about it, 2 bits remain. Solve Equation 5.4 for \(P_e\) with scipy.optimize.brentq to find that every classifier is wrong at least 0.3730 of the time.

5.4 What goes wrong

On small samples, estimates of mutual information from frequencies are too high, so two independent columns rarely give exactly zero. Compare an estimate with the estimate after you shuffle one column, which shows what independence alone gives.

Low mutual information does not mean that the output shows little, just as high entropy did not make the PIN hard to guess. Take a uniform 64-bit secret, and a channel that outputs all of it when its top 3 bits are zero, and a fixed symbol otherwise. Its mutual information is only 8.1686 bits, but a guesser who sees its output wins one time in eight. Min-entropy leakage catches this channel, at 61 bits. But it also averages across secrets, so it can stay small when one rare value is fully exposed.

Processing an output cannot add information about its source. If you compute a variable \(Z\) from \(Y\) alone, possibly with new randomness, the data-processing inequality says \[I(X; Z) \le I(X; Y). \tag{5.5}\] The condition matters, because a \(Z\) that also looked at \(X\) can know more.
