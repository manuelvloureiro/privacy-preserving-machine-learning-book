13  Private empirical risk minimization

Author

Manuel V. Loureiro

Published

Version 2026-10-30

Most of machine learning fits a model by minimizing its average loss on a training set. This chapter asks how to do that under differential privacy (DP) when the loss is convex. Noise can go into the output of a non-private solver, into the objective that the solver minimizes, or into each step of gradient descent. The chapter proves a privacy guarantee for each of the three methods. It also proves an accuracy guarantee for the third, which the next chapter scales to neural networks.

13.1 Empirical risk minimization

Each record \(z = (x, y)\) is a pair of a feature vector \(x\) and a label \(y\), and the dataset \(D = (z_1, \dots, z_n)\) holds \(n\) records. A parameter vector \(\theta\) in \(\mathbb R^d\) describes a model. A loss function \(\ell(\theta; z)\) measures how badly the model \(\theta\) fits the record \(z\). To fit a model is to choose \(\theta\) from a set of allowed values so that the total loss over the dataset is small. The definition also says how to measure an algorithm that only comes close to the best choice.

Definition 13.1 (Empirical risk minimization) Let \(\Theta \subseteq \mathbb R^d\) be a nonempty, closed, convex set of allowed parameters. The empirical risk of \(\theta\) on \(D\) is the total loss

\[ \mathcal L(\theta; D) = \sum_{i=1}^n \ell(\theta; z_i), \tag{13.1}\]

and \(\theta^* \in \Theta\) denotes a minimizer of \(\mathcal L(\cdot\,; D)\) over \(\Theta\). An algorithm that outputs \(\tilde\theta \in \Theta\) has excess empirical risk \(\mathbb E[\mathcal L(\tilde\theta; D)] - \mathcal L(\theta^*; D)\), where the expectation is over the algorithm’s coins only. The dataset is fixed.

The problem is called empirical risk minimization (ERM). In practice the loss on new data matters. But where a uniform convergence argument applies, a good empirical minimizer also has a small loss on new data. So this chapter studies only the empirical problem.

In this generality the problem is hopeless, so the chapter makes three assumptions. The set of allowed parameters is bounded, which its diameter measures. The loss is convex, so that a local minimum is a global one, and Lipschitz, so that it cannot change quickly. The definitions below make these terms precise, with the subgradient, which replaces the gradient where a convex function has a kink.

Definition 13.2 (Diameter, convexity, Lipschitz continuity)  

  • The diameter of \(\Theta\) is \(\|\Theta\|_2 = \sup_{\theta, \theta' \in \Theta}\|\theta - \theta'\|_2\).
  • A function \(f\) on a convex set \(K\) is convex if \(f(t\theta + (1-t)\theta') \le t f(\theta) + (1-t)f(\theta')\) for all \(\theta, \theta' \in K\) and \(t \in [0,1]\).
  • A function \(f\) on \(K\) is \(L\)-Lipschitz if \(|f(\theta) - f(\theta')| \le L\|\theta - \theta'\|_2\) for all \(\theta, \theta' \in K\).
  • A vector \(g\) is a subgradient of a convex \(f\) at \(\theta\) if \(f(\theta') \ge f(\theta) + \langle g, \theta' - \theta\rangle\) for all \(\theta'\). Where \(f\) is differentiable, its gradient \(\nabla f(\theta)\), the vector of partial derivatives, is the only subgradient.

So the chapter assumes that \(\Theta\) has finite diameter. It also assumes that, for every record \(z\), the loss \(\theta \mapsto \ell(\theta; z)\) is convex and \(L\)-Lipschitz on \(\mathbb R^d\). A convex function that is finite on all of \(\mathbb R^d\) has a subgradient at every point. Write \(\nabla\ell(\theta; z)\) for a gradient, or a subgradient where \(\ell\) is not differentiable. Lipschitz continuity matters to privacy because it bounds every gradient, and so the effect of one record on a gradient step.

Lemma 13.1 If a convex function \(f\) is \(L\)-Lipschitz on \(\mathbb R^d\), then every subgradient \(g\) of \(f\) satisfies \(\|g\|_2 \le L\).

Proof.

  1. Suppose \(g \ne 0\), take any point \(\theta\), and set \(u = g/\|g\|_2\). The definition of a subgradient at \(\theta' = \theta + u\) gives \(f(\theta + u) - f(\theta) \ge \langle g, u\rangle = \|g\|_2\).
  2. The Lipschitz condition gives \(f(\theta+u) - f(\theta) \le L\|u\|_2 = L\). The two bounds together give \(\|g\|_2 \le L\).

The most common losses are convex, and most of them are Lipschitz when the features are bounded.

Example 13.1 (Common losses) Take \(x, \theta \in \mathbb R^d\).

  • Linear regression, \(y \in \mathbb R\): the squared loss \(\ell(\theta; x, y) = (\langle x, \theta\rangle - y)^2\). It is convex, and Lipschitz only on bounded sets.
  • Logistic regression, \(y \in \{-1, 1\}\): \(\ell(\theta; x, y) = \ln\big(1 + e^{-y\langle x, \theta\rangle}\big)\). Its gradient is \(-y\,x/(1 + e^{y\langle x,\theta\rangle})\), of norm at most \(\|x\|_2\), so it is \(\|x\|_2\)-Lipschitz.
  • Geometric median, no label: \(\ell(\theta; x) = \|\theta - x\|_2\). By the triangle inequality it is \(1\)-Lipschitz. In one dimension it is \(|\theta - x|\), and its minimizer is the median.
  • Support vector machine (SVM), \(y \in \{-1, 1\}\): the hinge loss \(\ell(\theta; x, y) = \max(0, 1 - y\langle x, \theta\rangle)\). It is a maximum of two functions that are linear in \(\theta\), so it is convex and \(\|x\|_2\)-Lipschitz.

Stronger assumptions, such as strong convexity or smoothness of the loss, give faster rates, but the chapter does not need them. Until Section 13.5, the solver of this convex problem is a black box.

13.2 Why the minimizer is not private

An exact minimizer can reveal records outright, and the median is the simplest case.

Proposition 13.1 Let \(d = 1\), \(\ell(\theta; x) = |\theta - x|\), records in \([-R, R]\) with \(R > 0\), \(\Theta = [-R, R]\), and \(n\) odd. Then the empirical risk has a unique minimizer, the median \(x_{(m)}\) with \(m = (n+1)/2\), where \(x_{(1)} \le \dots \le x_{(n)}\) are the sorted records. The algorithm that outputs it is not \((\varepsilon,\delta)\)-DP for any \(\varepsilon\) and any \(\delta < 1\).

Proof.

  1. Away from the records, the function \(\theta \mapsto \sum_i |\theta - x_i|\) has slope equal to the number of records below \(\theta\) minus the number above. For \(\theta < x_{(m)}\) at least \(m\) records lie above, so the slope is at most \((m-1) - m = -1\). For \(\theta > x_{(m)}\) the slope is at least \(1\) in the same way. The function is continuous, so \(x_{(m)}\) is its unique minimizer.
  2. On the dataset with every record equal to \(-R\) the output is \(-R\), and on the dataset with every record equal to \(R\) it is \(R\). A path of \(n\) replacements joins the two datasets, so some neighbours \(D \sim D'\) along it have different outputs \(v \ne v'\).
  3. The algorithm is deterministic. For the event \(S = \{v\}\) this gives \(\Pr[M(D) \in S] = 1\) and \(\Pr[M(D') \in S] = 0\), and \(1 \le e^\varepsilon \cdot 0 + \delta\) fails for every \(\delta < 1\).

To privatize each record before any non-private algorithm is local DP, which needs far more data for the same accuracy. So the three methods below add noise after the data is pooled.

13.3 Output perturbation

The obvious method computes the minimizer and adds noise scaled to its sensitivity. But Proposition 13.1 shows that the minimizer can have large sensitivity, and regularization is the fix.

Polynomial regression shows the problem. With records \((x_i, y_i) \in \mathbb R^2\) and the squared loss \(\ell(\theta; x, y) = \big(\sum_{j=0}^{p}\theta_j x^j - y\big)^2\), the model is a polynomial of degree \(p\). If the degree is as high as \(p = n - 1\), then for distinct features the minimizer passes through every point. Its excess risk is zero, but it fits new data poorly and swings wildly when one point moves. These are two views of the same instability, as the left panel of Figure 13.1 shows.

Regularization adds a penalty that favours simple models. For a function \(N\) of the parameters alone, called the regularizer, and a weight \(\lambda > 0\), the regularized objective is

\[ F_D(\theta) = \mathcal L(\theta; D) + \lambda N(\theta). \tag{13.2}\]

At \(\lambda = 0\) there is no regularization, and as \(\lambda \to \infty\) the data is ignored. The usual choice is \(N(\theta) = \tfrac12\|\theta\|_2^2\). Its effect on sensitivity comes from strong convexity, which asks that the function curve upward by at least a fixed amount everywhere. For the regularized objective, that amount is the weight \(\lambda\).

Definition 13.3 (Strong convexity) For \(\lambda > 0\), a function \(f\) on a convex set \(K\) is \(\lambda\)-strongly convex if, for all \(\theta, \theta' \in K\) and \(t \in [0,1]\),

\[ f(t\theta + (1-t)\theta') \le t f(\theta) + (1-t) f(\theta') - \frac\lambda2\, t(1-t)\,\|\theta - \theta'\|_2^2 . \tag{13.3}\]

The function \(\tfrac12\|\theta\|_2^2\) is \(1\)-strongly convex, with equality, by the identity \(t\|a\|^2 + (1-t)\|b\|^2 - \|ta + (1-t)b\|^2 = t(1-t)\|a - b\|^2\). A \(\lambda\)-strongly convex function plus a convex function is \(\lambda\)-strongly convex. The next lemma shows that such a function grows at least quadratically away from its minimizer.

Lemma 13.2 Let \(f\) be \(\lambda\)-strongly convex on a convex set \(K\), with a minimizer \(\hat\theta\) over \(K\). Then for every \(\theta \in K\),

\[ f(\theta) - f(\hat\theta) \ge \frac\lambda2\|\theta - \hat\theta\|_2^2 . \tag{13.4}\]

In particular, the minimizer is unique.

Proof.

  1. For \(t \in (0, 1)\), the point \(\hat\theta + t(\theta - \hat\theta)\) lies in \(K\), so its value is at least \(f(\hat\theta)\).
  2. Strong convexity, applied with weight \(t\) on \(\theta\), bounds that value by \(t f(\theta) + (1-t) f(\hat\theta) - \frac\lambda2 t(1-t)\|\theta - \hat\theta\|_2^2\).
  3. The two bounds together, divided by \(t\), give \(f(\theta) - f(\hat\theta) \ge \frac\lambda2(1-t)\|\theta - \hat\theta\|_2^2\). Letting \(t \to 0\) gives the claim.
  4. A second minimizer \(\theta\) would have \(f(\theta) - f(\hat\theta) = 0\), which forces \(\theta = \hat\theta\).

This growth keeps the regularized minimizer stable. When one record changes, the two regularized objectives differ by a Lipschitz function. Each objective grows quadratically around its own minimizer, so the two minimizers cannot be far apart.

Theorem 13.1 (Sensitivity of the regularized minimizer) Let \(\Theta\) be nonempty, closed, convex and bounded. Suppose that for every record \(z\) the loss \(\ell(\cdot\,; z)\) is convex and \(L\)-Lipschitz on \(\Theta\), and that \(N\) is continuous and \(1\)-strongly convex. For each dataset \(D\), let \(\theta_D\) be the minimizer of \(F_D = \mathcal L(\cdot\,; D) + \lambda N\) over \(\Theta\). Then for all neighbours \(D \sim D'\), which differ in one replaced record,

\[ \|\theta_D - \theta_{D'}\|_2 \le \frac{2L}{\lambda}. \tag{13.5}\]

Proof.

  1. \(F_D\) is continuous on the closed bounded set \(\Theta\), so it has a minimizer, and it is \(\lambda\)-strongly convex, so the minimizer is unique by Lemma 13.2. The same holds for \(F_{D'}\).
  2. Write \(\theta = \theta_D\) and \(\theta' = \theta_{D'}\). Lemma 13.2 applied to each function gives \[ F_D(\theta') - F_D(\theta) \ge \frac\lambda2\|\theta - \theta'\|_2^2, \qquad F_{D'}(\theta) - F_{D'}(\theta') \ge \frac\lambda2\|\theta - \theta'\|_2^2 . \tag{13.6}\]
  3. Add the two inequalities. The left side becomes \(h(\theta') - h(\theta)\), where \(h = F_D - F_{D'}\), and the right side becomes \(\lambda\|\theta - \theta'\|_2^2\).
  4. If \(D\) and \(D'\) differ in record \(j\), then \(h(\cdot) = \ell(\cdot\,; z_j) - \ell(\cdot\,; z'_j)\) is a difference of two \(L\)-Lipschitz functions, so \(h(\theta') - h(\theta) \le 2L\|\theta - \theta'\|_2\).
  5. So \(\lambda\|\theta - \theta'\|_2^2 \le 2L\|\theta - \theta'\|_2\), and dividing by \(\lambda\|\theta - \theta'\|_2\) gives the claim. If \(\theta = \theta'\), there is nothing to prove.

The bound depends on neither \(n\) nor the dimension, and the Gaussian mechanism of the approximate DP chapter does the rest. Take a function \(f\) whose \(\ell_2\) sensitivity, the largest change in Euclidean norm between neighbours, is \(\Delta_2 f\). The mechanism adds Gaussian noise \(\mathcal N(0, \sigma^2 I_d)\) with standard deviation \(\sigma\) in each coordinate. For every \(\varepsilon > 0\) and \(\delta \in (0,1)\) it is \((\varepsilon, \delta)\)-DP, the relaxation that allows an additive slack \(\delta\), when

\[ \sigma = \frac{\Delta_2 f}{\varepsilon}\sqrt{2\ln(1/\delta) + \varepsilon}. \tag{13.7}\]

The mechanism applied to the regularized minimizer \(f(D) = \theta_D\), with \(\Delta_2 f = 2L/\lambda\), gives the first private algorithm.

Theorem 13.2 (Output perturbation) Under the assumptions of Theorem 13.1, let \(\varepsilon > 0\) and \(\delta \in (0,1)\). The algorithm that outputs \(\tilde\theta = \theta_D + b\), where \(\theta_D\) is the regularized minimizer, with \(b \sim \mathcal N(0, \sigma^2 I_d)\) and

\[ \sigma = \frac{2L}{\lambda}\cdot\frac{\sqrt{2\ln(1/\delta) + \varepsilon}}{\varepsilon}, \tag{13.8}\]

is \((\varepsilon, \delta)\)-DP. So is its projection onto \(\Theta\).

Proof. The map \(D \mapsto \theta_D\) has \(\ell_2\) sensitivity at most \(2L/\lambda\) by Theorem 13.1, so the Gaussian mechanism gives the guarantee. The projection is post-processing.

Output perturbation is simple and works with any exact solver. But its accuracy is often weak, because the regularization that privacy needs can be far from the one that fits the data best.

13.4 Objective perturbation

The second method adds noise to the objective instead of the output. It minimizes

\[ J_b(\theta) = \mathcal L(\theta; D) + \frac\lambda2\|\theta\|_2^2 + \langle b, \theta\rangle \tag{13.9}\]

for a random vector \(b\), and releases the exact minimizer. The linear term rewards or penalizes each direction of the parameter space by a random amount.

The proof below is for losses of generalized linear form, such as logistic regression and smoothed versions of the hinge loss. Such a loss is \(\ell(\theta; x, y) = \phi(\langle x, \theta\rangle, y)\). For each label \(y\), the scalar function \(u \mapsto \phi(u, y)\) is convex and twice continuously differentiable, with derivatives \(|\phi'| \le L\) and \(0 \le \phi'' \le \beta\). The features satisfy \(\|x\|_2 \le 1\). So the gradient \(\nabla\ell = \phi'(\langle x,\theta\rangle, y)\,x\) has norm at most \(L\). The Hessian, the matrix of second derivatives, is \(\nabla^2\ell = \phi''(\langle x,\theta\rangle, y)\,xx^\top\), with rank at most one and eigenvalues in \([0, \beta]\).

The proof compares the densities of the output on two neighbouring datasets. So it needs a criterion in terms of densities, from the approximate DP chapter. Write \(p_D\) for the density of the output when the dataset is \(D\). The privacy loss of an output \(\theta\) is \(\ln\big(p_D(\theta)/p_{D'}(\theta)\big)\), which is large when \(\theta\) is much more likely under \(D\) than under \(D'\). The criterion says that \(M\) is \((\varepsilon,\delta)\)-DP if, for every ordered pair of neighbours, an output drawn from \(M(D)\) has privacy loss above \(\varepsilon\) with probability at most \(\delta\).

Theorem 13.3 (Objective perturbation) Let \(\Theta = \mathbb R^d\), and let \(\ell\) be a generalized linear loss as above, with \(|\phi'| \le L\), \(0 \le \phi'' \le \beta\) and features of norm at most \(1\). Let \(\varepsilon \in (0, 4]\) and \(\delta \in (0,1)\), and set

\[ \lambda \ge \frac{\beta}{e^{\varepsilon/2} - 1}, \qquad \sigma = \frac{4L\big(1 + \sqrt{2\ln(1/\delta)}\big)}{\varepsilon}. \tag{13.10}\]

Then the algorithm that draws \(b \sim \mathcal N(0, \sigma^2 I_d)\) and outputs the exact minimizer \(\tilde\theta\) of \(J_b\) is \((\varepsilon, \delta)\)-DP.

Proof.

  1. The output as a function of the noise. For each \(b\), the function \(J_b\) is continuous and \(\lambda\)-strongly convex on \(\mathbb R^d\), so it has a unique minimizer, where its gradient vanishes. So \(\tilde\theta = \theta\) exactly when \(b = g_D(\theta)\), where \(g_D(\theta) = -\nabla\mathcal L(\theta; D) - \lambda\theta\). Every \(\theta\) is the minimizer for the noise \(g_D(\theta)\), and each noise has one minimizer, so \(g_D\) is a bijection of \(\mathbb R^d\) and \(\tilde\theta = g_D^{-1}(b)\).
  2. The density of the output. The map \(g_D\) is continuously differentiable with Jacobian \(-(H_D(\theta) + \lambda I)\), where \(H_D(\theta) = \sum_i \nabla^2\ell(\theta; z_i)\) is positive semidefinite. By the change of variables formula, \(\tilde\theta\) has density \[ p_D(\theta) = \varphi_\sigma\big(g_D(\theta)\big)\,\det\big(H_D(\theta) + \lambda I\big), \tag{13.11}\] where \(\varphi_\sigma\) is the density of \(\mathcal N(0,\sigma^2 I_d)\).
  3. The determinants. Let \(D\) and \(D'\) differ in the last record, \(z = (x, y)\) in \(D\) and \(z' = (x', y')\) in \(D'\). Fix \(\theta\) and write \(A = \sum_{i<n}\nabla^2\ell(\theta; z_i) + \lambda I\), which satisfies \(A \succeq \lambda I\). Then \(H_D + \lambda I = A + a\,xx^\top\) with \(a = \phi''(\langle x,\theta\rangle, y) \in [0,\beta]\). The matrix determinant lemma gives \[ \det(A + a\,xx^\top) = \det(A)\,\big(1 + a\,x^\top A^{-1}x\big) \in \big[\det A,\ (1 + \beta/\lambda)\det A\big], \tag{13.12}\] because \(0 \le x^\top A^{-1} x \le \|x\|_2^2/\lambda \le 1/\lambda\). The same holds for \(D'\). So the ratio of the two determinants is at most \(1 + \beta/\lambda \le e^{\varepsilon/2}\), by the choice of \(\lambda\).
  4. The Gaussian factors. The two noise vectors that lead to \(\theta\) differ by \(u = g_{D'}(\theta) - g_D(\theta) = \nabla\ell(\theta; z) - \nabla\ell(\theta; z')\). This vector has norm at most \(2L\), and it lies in the subspace \(V\) spanned by \(x\) and \(x'\), which does not depend on \(\theta\). With \(b = g_D(\theta)\) and \(P_V\) the orthogonal projection onto \(V\), \[ \ln\frac{\varphi_\sigma(b)}{\varphi_\sigma(b + u)} = \frac{2\langle b, u\rangle + \|u\|_2^2}{2\sigma^2} \le \frac{2L\,\|P_V b\|_2}{\sigma^2} + \frac{2L^2}{\sigma^2}, \tag{13.13}\] by the Cauchy–Schwarz inequality applied to \(\langle b, u\rangle = \langle P_V b, u\rangle\).
  5. The privacy loss. When the output is drawn from \(M(D)\), the vector \(g_D(\tilde\theta)\) is the noise \(b\) itself. Steps 2 to 4 bound the privacy loss at the output by \[ \ln\frac{p_D(\tilde\theta)}{p_{D'}(\tilde\theta)} \le \frac\varepsilon2 + \frac{2L\,\|P_V b\|_2}{\sigma^2} + \frac{2L^2}{\sigma^2}. \tag{13.14}\]
  6. The tail. The subspace \(V\) has dimension \(d_V \le 2\), so \(\|P_V b\|_2^2/\sigma^2\) is chi-squared with \(d_V\) degrees of freedom. Its tail is at most that of two degrees of freedom, which is \(e^{-r/2}\) beyond \(r\). Write \(s = \sqrt{2\ln(1/\delta)}\) for the cut-off. Then \[ \Pr\big[\|P_V b\|_2 > \sigma s\big] \le e^{-s^2/2} = \delta . \tag{13.15}\]
  7. Outside that event, substituting \(\sigma = 4L(1+s)/\varepsilon\) into step 5 gives \[ \ln\frac{p_D(\tilde\theta)}{p_{D'}(\tilde\theta)} \le \frac\varepsilon2 + \frac\varepsilon2\left(\frac{s}{1+s} + \frac{\varepsilon}{4(1+s)^2}\right) \le \frac\varepsilon2 + \frac\varepsilon2\cdot\frac{s + 1}{1+s} = \varepsilon, \tag{13.16}\] where the second step uses \(\varepsilon \le 4\) and \(1/(1+s)^2 \le 1/(1+s)\).
  8. The privacy loss criterion turns this bound into \((\varepsilon,\delta)\)-DP.

The theorem has a practical weakness. It holds only for the exact minimizer, and a real solver never returns one. Iterative solvers such as gradient descent only approach the minimizer. Floating-point arithmetic cannot represent most real numbers, and even a naive floating-point Laplace mechanism leaks the data through the low-order bits of its output (Mironov). Later versions of objective perturbation need only an approximate minimizer.

13.5 Gradient perturbation

The third method, now the standard one, runs gradient descent and adds noise to each gradient. Its analysis starts from the non-private algorithm. Write \(\Pi_\Theta(u) = \arg\min_{\theta\in \Theta}\|\theta - u\|_2\) for the projection onto \(\Theta\), the closest point of \(\Theta\), which exists and is unique because \(\Theta\) is closed and convex.

The definition leaves the step direction \(G_t\) random, so that one analysis covers exact gradients, gradients of one sampled record, and the noisy gradients of the private algorithm.

Definition 13.4 (Projected stochastic gradient descent) Fix a start \(\theta_0 \in \Theta\), a number of steps \(T\) and a learning rate \(\eta > 0\), also called the step size. For \(t = 1, \dots, T\), draw a random vector \(G_t\) and set

\[ \theta_t = \Pi_\Theta(\theta_{t-1} - \eta\,G_t). \tag{13.17}\]

Output the average \(\bar\theta = \frac1T\sum_{t=0}^{T-1}\theta_t\). With \(G_t = \nabla\mathcal L(\theta_{t-1}; D)\) this is projected gradient descent. With \(G_t = n\,\nabla\ell(\theta_{t-1}; z_{I_t})\), for an index \(I_t\) drawn uniformly from \(\{1,\dots,n\}\), it is projected stochastic gradient descent (SGD).

A step moves against the gradient, the direction of steepest increase. The projection brings a step that leaves \(\Theta\) back to the nearest allowed point. The convergence proof compares each iterate with the minimizer, and for that it uses the fact that projection never moves a point farther from any point of \(\Theta\).

Lemma 13.3 For every \(u \in \mathbb R^d\) and every \(\theta \in \Theta\), \(\|\Pi_\Theta(u) - \theta\|_2 \le \|u - \theta\|_2\).

Proof.

  1. Let \(v = \Pi_\Theta(u)\). For \(t \in (0,1]\) the point \(v + t(\theta - v)\) is in \(\Theta\), so it is no closer to \(u\) than \(v\): \(\|u - v - t(\theta-v)\|^2 \ge \|u - v\|^2\). Expanding, dividing by \(t\) and letting \(t \to 0\) gives \(\langle u - v, \theta - v\rangle \le 0\).
  2. Then \(\|u - \theta\|^2 = \|u - v\|^2 + \|v - \theta\|^2 + 2\langle u - v, v - \theta\rangle \ge \|v - \theta\|^2\), because the last term is nonnegative by step 1.

The convergence theorem asks only that each \(G_t\) is right on average and not too large.

Theorem 13.4 (Convergence of projected SGD) Let \(F\) be convex on \(\mathbb R^d\), and let \(\theta^*\) minimize \(F\) over \(\Theta\). Suppose that, given \(\theta_0, \dots, \theta_{t-1}\), the conditional mean \(\mathbb E[G_t \mid \theta_0, \dots, \theta_{t-1}]\) is a subgradient of \(F\) at \(\theta_{t-1}\), and that \(\mathbb E\|G_t\|_2^2 \le G^2\) for every \(t\). With learning rate \(\eta = \|\Theta\|_2/(G\sqrt T)\),

\[ \mathbb E[F(\bar\theta)] - F(\theta^*) \le \frac{\|\Theta\|_2\, G}{\sqrt T}. \tag{13.18}\]

Proof.

  1. By Lemma 13.3 with \(\theta = \theta^*\), \[ \|\theta_t - \theta^*\|^2 \le \|\theta_{t-1} - \eta G_t - \theta^*\|^2 = \|\theta_{t-1} - \theta^*\|^2 - 2\eta\langle G_t, \theta_{t-1} - \theta^*\rangle + \eta^2\|G_t\|^2 . \tag{13.19}\]
  2. Condition on the past and let \(g\) be the conditional mean of \(G_t\), a subgradient at \(\theta_{t-1}\). The definition of a subgradient gives \(\langle g, \theta_{t-1} - \theta^*\rangle \ge F(\theta_{t-1}) - F(\theta^*)\). Taking expectations in step 1, \[ \mathbb E[F(\theta_{t-1})] - F(\theta^*) \le \frac{\mathbb E\|\theta_{t-1} - \theta^*\|^2 - \mathbb E\|\theta_t - \theta^*\|^2}{2\eta} + \frac{\eta G^2}{2}. \tag{13.20}\]
  3. Summing over \(t = 1, \dots, T\), the distances telescope. The first is at most \(\|\Theta\|_2^2\) and the last is nonnegative, so \[ \sum_{t=0}^{T-1}\big(\mathbb E[F(\theta_t)] - F(\theta^*)\big) \le \frac{\|\Theta\|_2^2}{2\eta} + \frac{T\eta G^2}{2}. \tag{13.21}\]
  4. The average \(\bar\theta\) lies in \(\Theta\), and convexity gives \(F(\bar\theta) \le \frac1T\sum_t F(\theta_t)\). Step 3 divided by \(T\), with the value of \(\eta\), makes both terms \(\|\Theta\|_2 G/(2\sqrt T)\).

For the empirical risk, the theorem gives the number of steps that each method needs. The bound \(G\) on the step comes from the bound \(L\) on every gradient.

Corollary 13.1 Suppose that \(\Theta\) has finite diameter \(\|\Theta\|_2\) and that every loss \(\ell(\cdot\,; z)\) is convex and \(L\)-Lipschitz on \(\mathbb R^d\). Then gradient descent and SGD both reach excess empirical risk at most \(\alpha\) after \(T = \lceil n^2L^2\|\Theta\|_2^2/\alpha^2\rceil\) steps. Gradient descent evaluates \(nT\) gradients of \(\ell\), and SGD evaluates \(T\).

Proof.

  1. For gradient descent, \(G_t = \sum_i\nabla\ell(\theta_{t-1}; z_i)\) is a subgradient of \(\mathcal L\), and by Lemma 13.1 its norm is at most \(nL\).
  2. For SGD, the conditional mean of \(G_t = n\nabla\ell(\theta_{t-1}; z_{I_t})\) is \(\frac1n\sum_i n\nabla\ell(\theta_{t-1}; z_i)\), the same subgradient. Its second moment is \(\frac1n\sum_i n^2\|\nabla\ell(\theta_{t-1}; z_i)\|^2 \le n^2L^2\).
  3. In both cases \(G = nL\), and Theorem 13.4 gives excess risk at most \(\|\Theta\|_2 nL/\sqrt T \le \alpha\).

For a constant \(\alpha\), gradient descent costs about \(n^3\) gradient evaluations and SGD about \(n^2\). SGD is also easier to make private, because each step touches one record. Private SGD adds Gaussian noise to each sampled gradient, at the level \(\sigma\) that the privacy proof below needs, and its learning rate allows for the extra noise.

Definition 13.5 (Private SGD) Let \(\varepsilon \in (0,1]\) and \(\delta \in (0,1)\). Run projected SGD for \(T = n^2\) steps with

\[ G_t = n\,\nabla\ell(\theta_{t-1}; z_{I_t}) + b_t, \qquad b_t \sim \mathcal N(0, \sigma^2 I_d), \qquad \sigma = \frac{16\,nL\sqrt{\ln(3.3n/\delta)\,\ln(2/\delta)}}{\varepsilon}, \tag{13.22}\]

with fresh, independent indices \(I_t\) and noise \(b_t\), and learning rate \(\eta = \|\Theta\|_2/(G\sqrt T)\) where \(G^2 = n^2L^2 + d\sigma^2\).

Accuracy is the easier half, because the noise has mean zero and only makes the second moment larger.

Theorem 13.5 With \(\ell(\cdot\,;z)\) convex and \(L\)-Lipschitz on \(\mathbb R^d\), private SGD satisfies

\[ \mathbb E[\mathcal L(\bar\theta; D)] - \mathcal L(\theta^*; D) \le \|\Theta\|_2\sqrt{L^2 + \frac{d\sigma^2}{n^2}} \le \|\Theta\|_2\,L\left(1 + \frac{16\sqrt{d\,\ln(3.3n/\delta)\ln(2/\delta)}}{\varepsilon}\right). \tag{13.23}\]

Proof.

  1. Given the past, \(b_t\) has mean zero and is independent of \(I_t\), so the conditional mean of \(G_t\) is the subgradient of step 2 of Corollary 13.1.
  2. Expanding the square, \[ \mathbb E\|G_t\|^2 = n^2\,\mathbb E\|\nabla\ell(\theta_{t-1}; z_{I_t})\|^2 + 2n\,\mathbb E\langle\nabla\ell(\theta_{t-1}; z_{I_t}), b_t\rangle + \mathbb E\|b_t\|^2 \le n^2L^2 + 0 + d\sigma^2 . \tag{13.24}\] The first term is bounded by Lemma 13.1. The middle term vanishes because \(b_t\) is independent of the gradient and has mean zero. The last is a sum of \(d\) squared Gaussians of variance \(\sigma^2\).
  3. Theorem 13.4 with \(T = n^2\) gives \(\|\Theta\|_2 G/n\), which is the first bound. The second uses \(\sqrt{a + b} \le \sqrt a + \sqrt b\) and the value of \(\sigma\).

Up to logarithmic factors, the excess risk is \(O\big(\|\Theta\|_2 L\sqrt{d\ln(1/\delta)}/\varepsilon\big)\), so the average excess risk per record falls as \(1/n\). The price of privacy is the factor \(\sqrt d\), and Bassily, Smith and Thakurta proved that some dependence of this kind is unavoidable. But the constant \(16\) comes from a loose chain of bounds. For example, with \(n = 10{,}000\), \(\varepsilon = 1\) and \(\delta = 10^{-6}\), the noise is \(\sigma = 299.9\,nL\). With \(d = 100\), the bound per record is \(\|\Theta\|_2L(1 + 2999)/10{,}000 = 0.30\,\|\Theta\|_2L\). The next chapter replaces this chain with a much tighter one.

The privacy proof uses three tools. The first is the Gaussian mechanism, restated above. The second is amplification by subsampling, which says that a mechanism run on one random record is more private than the same mechanism run on a fixed record.

Lemma 13.4 (Amplification by sampling one record) Let \(M_0\) be a mechanism whose input is a single record and which satisfies \(\Pr[M_0(z)\in S] \le e^{\varepsilon_0}\Pr[M_0(z')\in S] + \delta_0\) for all records \(z, z'\) and all events \(S\). Let \(M(D) = M_0(z_I)\) with \(I\) uniform on \(\{1,\dots,n\}\). Then \(M\) is \((\varepsilon_1, \delta_0/n)\)-DP with

\[ \varepsilon_1 = \ln\left(1 + \frac{e^{\varepsilon_0} - 1}{n}\right) \le \frac{e^{\varepsilon_0}-1}{n}. \tag{13.25}\]

Proof.

  1. Let \(D\) and \(D'\) differ in record \(j\), fix an event \(S\), and write \(p_i = \Pr[M_0(z_i)\in S]\) and \(p'_j = \Pr[M_0(z'_j)\in S]\). Let \(r\) be the average of \(p_i\) over \(i \ne j\), and write \(q = 1/n\) for the sampling rate. Then \[ P = \Pr[M(D)\in S] = (1-q)r + q p_j, \qquad P' = \Pr[M(D')\in S] = (1-q)r + q p'_j . \tag{13.26}\]
  2. The hypothesis, applied to \(z_j\) against \(z'_j\) and against each \(z_i\) and then averaged, gives two bounds: \[ p_j - p'_j \le (e^{\varepsilon_0} - 1)p'_j + \delta_0, \qquad p_j - p'_j \le e^{\varepsilon_0}r - p'_j + \delta_0 . \tag{13.27}\]
  3. Let \(c = e^{\varepsilon_0} - 1\) and take the convex combination of the two bounds with weights \(w\) and \(1-w\), where \(1 - w = c(1-q)/e^{\varepsilon_0} \in [0,1)\). The coefficient of \(r\) becomes \(c(1-q)\), and that of \(p'_j\) becomes \(we^{\varepsilon_0} - 1 = cq\). So \[ p_j - p'_j \le c\big((1-q)r + q p'_j\big) + \delta_0 = cP' + \delta_0 . \tag{13.28}\]
  4. Then \(P = P' + q(p_j - p'_j) \le (1 + q c)P' + q\delta_0\), which is the claim. The inequality \(\ln(1+x) \le x\) gives the simpler bound on \(\varepsilon_1\).

For \(\varepsilon_0 \le 1\), convexity of the exponential gives \(e^{\varepsilon_0} - 1 \le (e-1)\varepsilon_0 \le 2\varepsilon_0\). So a sample of one record of \(n\) cuts the privacy parameter by a factor of about \(n/2\).

The third tool is advanced composition, from the advanced composition chapter. Take \(k\) mechanisms in sequence, each \((\varepsilon_0,\delta_0)\)-DP and each chosen adaptively from the outputs of the previous ones. Their sequence is \((\varepsilon, k\delta_0 + \delta')\)-DP for every \(\delta' \in (0,1)\), where

\[ \varepsilon = \varepsilon_0\sqrt{2k\ln(1/\delta')} + k\varepsilon_0\,\frac{e^{\varepsilon_0} - 1}{e^{\varepsilon_0} + 1} \le \varepsilon_0\sqrt{2k\ln(1/\delta')} + \frac{k\varepsilon_0^2}{2}, \tag{13.29}\]

and the inequality uses \((e^{x}-1)/(e^{x}+1) = \tanh(x/2) \le x/2\) for \(x \ge 0\).

The proof uses the three tools in turn. The Gaussian noise protects the sampled record in one step, the random choice of that record makes the step more private, and advanced composition adds up the steps.

Theorem 13.6 (Privacy of private SGD) For \(\varepsilon \in (0,1]\) and \(\delta \in (0,1)\), private SGD is \((\varepsilon, \delta)\)-DP, even if it releases every iterate \(\theta_1, \dots, \theta_T\).

Proof.

  1. One step, fixed index. Fix the previous iterate and the index \(i\). The step releases a post-processing of \(n\nabla\ell(\theta_{t-1}; z_i) + b_t\). As a function of the single record \(z_i\), the vector \(n\nabla\ell\) has \(\ell_2\) sensitivity at most \(2nL\), by Lemma 13.1. Set \(\varepsilon_0 = \varepsilon/\big(4\sqrt{2\ln(2/\delta)}\big)\), which is below \(1\), and \(\delta_0 = \delta/(2n)\). The Gaussian mechanism is \((\varepsilon_0,\delta_0)\)-DP with respect to \(z_i\) at the noise level \[ \sigma_0 = \frac{2nL}{\varepsilon_0}\sqrt{2\ln(1/\delta_0) + \varepsilon_0} \le \frac{2nL}{\varepsilon_0}\sqrt{2\ln\frac{2\sqrt e\,n}{\delta}} \le \frac{2nL}{\varepsilon_0}\sqrt{2\ln\frac{3.3n}{\delta}} = \sigma, \tag{13.30}\] where the first inequality uses \(\varepsilon_0 \le 1 = 2\ln\sqrt e\), and the last equality is the \(\sigma\) of Definition 13.5. Noise of variance \(\sigma^2 \ge \sigma_0^2\) is noise of variance \(\sigma_0^2\) plus an independent Gaussian of variance \(\sigma^2 - \sigma_0^2\), a post-processing, so the step is \((\varepsilon_0,\delta_0)\)-DP with respect to \(z_i\).
  2. One step, random index. By Lemma 13.4, each step is \((\varepsilon_1, \delta_0/n)\)-DP with respect to the dataset, where \(\varepsilon_1 \le (e^{\varepsilon_0}-1)/n \le 2\varepsilon_0/n\).
  3. All steps. Each step is chosen adaptively from the previous iterates. Advanced composition over \(T = n^2\) steps with \(\delta' = \delta/2\) gives total failure probability \(n^2\cdot\delta/(2n^2) + \delta/2 = \delta\), and privacy parameter \[ \varepsilon_1\sqrt{2n^2\ln(2/\delta)} + \frac{n^2\varepsilon_1^2}{2} \le 2\varepsilon_0\sqrt{2\ln(2/\delta)} + 2\varepsilon_0^2 = \frac\varepsilon2 + 2\varepsilon_0^2 . \tag{13.31}\]
  4. Finally, the second term is small because \(\varepsilon \le 1\) and \(\ln(2/\delta) > \ln 2 > 1/8\): \[ 2\varepsilon_0^2 = \frac{\varepsilon^2}{16\ln(2/\delta)} \le \frac\varepsilon2 . \tag{13.32}\] The average \(\bar\theta\) is a post-processing of the iterates.

The privacy cost per step is about \(\varepsilon/n\), and composition over \(n^2\) steps multiplies it by only \(\sqrt{n^2} = n\). Each piece of the argument is generic, so the same recipe extends to models with no convergence theorem.
